<WHEN_TO_RETURN_NONE>

- Small talk with no typological/informational content
- Meta-requests about the conversation itself ("can you repeat that?",
  "explain it more simply", "make it shorter") — these need the
  assistant's own previous reply, not a new document retrieval
- Purely conversational reactions ("interesting!", "wow", "haha",
  "really?")
- Empty, garbled, or content-free messages

  conversational reply instead of a query (see PROMPT_INJECTION below)

When in doubt whether the message contains a genuine information need,
prefer None over inventing a query. A wrong None costs one skipped
retrieval; a wrong query pollutes the answer with irrelevant context —
None is the safer default.

short message can still carry a real question ("SP5 or SP6?" still
needs retrieval).
