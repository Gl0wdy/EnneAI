# EnneAI

Проект по персонализованной агентизации работы с типологическими данными через Telegram-бота с помощью крупных языковых моделей и RAG-инструментов

### Основной модуль

```text
src/enneai/
├── main.py              # точка входа: запуск бота и polling loop
├── config.py            # загрузка переменных окружения
├── ai/                  # интеграция с LLM и модулями ответов
│   ├── llm/             # работа с OpenRouter и ротацией ключей
│   ├── modules/         # типологические модули и промпты
│   │   ├── jung/        # модель Юнга
│   │   └── naranjo/     # модель Наранхо
│   └── rag/             # контекст, эмбеддинги, хранение и поиск
├── db/                  # модели данных, MongoDB, шифрование и репозитории
├── telegram/            # aiogram handlers, FSM, middleware, клавиатуры
├── utils/               # вспомогательные утилиты и обработка данных
└── __init__.py
```

### Данные и контекст

```text
data/
├── corr/                # корреляционные данные и таблицы
├── ennea/               # базовый контекст по эннеаграмме
├── jungian/             # данные по юнгианской модели
├── psychosophy/         # психософский контекст
├── socio/               # соционические семантические данные и контекст
└── ...
```

### Инфраструктура

```text
compose.yaml            # Docker Compose: бот, MongoDB, Qdrant
Dockerfile              # сборка контейнера приложения
pyproject.toml          # зависимости проекта и настройки Python
```

## Логика

- `telegram/` отвечает за взаимодействие с пользователем в Telegram.
- `db/` хранит пользователей, сообщения и обеспечивает безопасное хранение данных.
- `ai/llm/` работает с внешним LLM API и управляет ключами доступа.
- `ai/rag/` подготавливает и ищет релевантный контекст по эмбеддингам.
- `data/` содержит типологические и контекстные материалы для генерации ответов.
